# Incremental roadmap

This roadmap implements the greenfield master brief expressed in the [README](../../README.md) and [charter](../business/project-charter.md). It does not inherit a hackathon challenge sequence and is separate from Agentic SDLC work. **Milestones 1–16 are delivered within their recorded local/reference scopes; Milestones 17–24 are PLANNED and not started.** Runtime evidence comprises the Python foundation, offline dataset tools, simulated-fixture benchmark, local structured-evidence validation/admission, draft-policy lexical retrieval, authored-query evaluation and non-binding provisional rule findings and actual framework execution and governed internal tools and deterministic offline workflow/checkpoints plus real local MCP client/server transport; model behavior remains simulated; it does not establish a processing service or live model evaluation. Each milestone ends with reviewable evidence and an explicit status update.

Security, tests, provenance, basic telemetry and cost limits start with their first relevant component; later milestones deepen them rather than defer all controls. No milestone is complete solely because code exists. Actual Azure calls in any milestone require separate deployment/spending authorization; local progress uses explicitly labeled simulations where necessary.

Working definitions: **IMPLEMENTED** means an artifact/code path exists; **TESTED** adds a named environment and recorded checks/results; **SIMULATED** means a stub or injected scenario exercised a contract without proving the live dependency; **PLANNED** means intended only. Track capability and environment separately; documentation completion never promotes runtime status.

Approved requests govern scope: M1–M15 remain delivered as recorded. The approved M16 request adds a minimal offline FastAPI adapter over existing M12/M15 capabilities, not a full authenticated upload/scanning/persistence service. Those deferred intake/outbox capabilities require later scope. M17 reviewer UI and M18–24 deepening remain planned. M8's four lexical failures, M12 timing sensitivity and M15 volatile identity/audit limitations remain unresolved. Historical milestone records retain their original scope.
