# Incremental roadmap

This roadmap implements the greenfield master brief expressed in the [README](../../README.md) and [charter](../business/project-charter.md). It does not inherit a hackathon challenge sequence and is separate from Agentic SDLC work. **Milestones 1–10 are delivered within their recorded scope; Milestones 11–18 are PLANNED and not started.** Runtime evidence comprises the Python foundation, offline dataset tools, simulated-fixture benchmark, local structured-evidence validation/admission, draft-policy lexical retrieval, authored-query evaluation and non-binding provisional rule findings and actual framework execution with a simulated client; it does not establish a processing service or live model evaluation. Each milestone ends with reviewable evidence and an explicit status update.

Security, tests, provenance, basic telemetry and cost limits start with their first relevant component; later milestones deepen them rather than defer all controls. No milestone is complete solely because code exists. Actual Azure calls in any milestone require separate deployment/spending authorization; local progress uses explicitly labeled simulations where necessary.

Working definitions: **IMPLEMENTED** means an artifact/code path exists; **TESTED** adds a named environment and recorded checks/results; **SIMULATED** means a stub or injected scenario exercised a contract without proving the live dependency; **PLANNED** means intended only. Track capability and environment separately; documentation completion never promotes runtime status.

Approved requests govern scope: M1–M10 remain delivered as recorded. M10 adds a real Microsoft Agent Framework foundation before the deferred ingestion service. Its bounded review/explanation assistant retains the existing authority boundary; it does not complete later live agent workflows. Intake/scanning/API/persistence remain planned for M11, with later work in M12–18. Approved policy publication, hybrid retrieval and operational rules remain planned; M8's four lexical failures are unresolved. Historical milestone records retain their then-current plans; see [M10 implementation evidence](milestone-10.md).
