The template's 1 GiB daily cap/30-day telemetry, seven-day database backup and 30-day blob-delete retention are **review candidates**, not approved financial or retention policies. Key Vault purge protection and retained recovery artifacts can prevent immediate deletion and must be included in residual-cost planning.

Approve actual experiment/monthly ceilings and operator stop thresholds before any cloud validation/provisioning; do not substitute a budget alert for an enforceable stop/expiry procedure. Threshold candidates are 50/80/100%, with an operator stop/teardown action before the approved limit and later residual-resource/cost checks. No exact hard spending guarantee can be inferred from delayed Azure billing alerts. If required private services are unaffordable, deployment remains blocked; do not bypass APIM or expose databases/backends.
